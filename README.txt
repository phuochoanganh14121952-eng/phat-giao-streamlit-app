PHẬT GIÁO & LỜI PHẬT DẠY – STREAMLIT v1.0

CHẠY TRÊN MÁY
1. Cài Python 3.11 hoặc 3.12
2. pip install -r requirements.txt
3. streamlit run app.py

DEPLOY STREAMLIT COMMUNITY CLOUD
1. Tạo repository GitHub mới.
2. Upload toàn bộ file/thư mục của project.
3. Mở Streamlit Community Cloud.
4. Chọn repository.
5. Main file path: app.py
6. Deploy.
7. Khi có link *.streamlit.app, kiểm tra app rồi lưu vào KHO WEBSITE PHƯỚC.

GHI CHÚ
- Bản v1.0 không bắt buộc API.
- Có thể nâng cấp Gemini API ở v1.1.
